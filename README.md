# GrantNavigator
Данный проект создан в ходе изучения курса разработки полного цикла. Первоначально взятая идея проекта звучит так: "Грантовый кабинет: создание заявок, отслеживание дедлайнов, ИИ-проверка соответствия критериям конкурса". В репозитории ведутся обновления README, помимо базовых компонентов он содержит записи типа "лайфстайл" для простоты понимания.
